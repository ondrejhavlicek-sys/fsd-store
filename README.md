# fsd-store

Clickable prototype of the makro B2B eshop: homepage, category page, product detail, cart, checkout and header cart preview. Mock data, Czech UI.

```bash
python3 serve.py 5190
```

Open http://localhost:5190/index.html. See [docs/PROTOTYPE-NOTES.md](docs/PROTOTYPE-NOTES.md) for the screens, structure, deviations and open decisions.
